# Academic Deep Research — 报告模板

## subreports/round-N.md 模板

```markdown
# Round N: [轮次目标]

## 本轮问题
[本轮要回答的具体问题]

## 检索策略
- **学术源**：检索了什么、每源上限多少条
- **网页源**：检索了什么、上限多少条
- **检索式**：具体的关键词/查询

## 关键发现
1. [发现1] — 来源：[paper_uid / URL] — 置信度：
2. [发现2] — 来源：[paper_uid / URL] — 置信度：
3. [发现3] — 来源：[paper_uid / URL] — 置信度：

## 假设状态
| 假设 | 验证结果 | 证据 | 置信度 |
|---|---|---|---|
| [假设1] | 支持/反驳/不确定 | | |
| [假设2] | 支持/反驳/不确定 | | |

## 新假设（本轮产生的）
1. [新假设1] — 需要下一轮验证

## 本轮结论
[本轮回答了什么、还有哪些不确定]

## 下一步建议
[下一轮该聚焦什么]
```

## deep_research_report.md 模板

```markdown
# 深度调研报告：[主题]

## 执行摘要（1 页）
[问题/结论/建议/风险，可直接给决策者看]

## 1. 问题背景
[用户原始问题 + 澄清后的结构化问题]

## 2. 调研方法
[共几轮、每轮目标、检索源、覆盖范围]

## 3. 关键发现（按主题聚类）

### 3.1 [主题A]
[发现 + 证据 + 来源]

### 3.2 [主题B]
...

## 4. 证据冲突分析
| 冲突点 | 甲方证据 | 乙方证据 | 可能原因 | 当前判断 |
|---|---|---|---|---|
| | | | | |

## 5. 方案对比
| 方案 | 优势 | 劣势 | 适用条件 | 风险 |
|---|---|---|---|---|
| [方案A] | | | | |
| [方案B] | | | | |

## 6. 最终建议
[推荐方案 + 理由 + 关键假设]

## 7. 风险评估
[如果推荐错了，代价是什么]
[关键假设如果不成立，Plan B 是什么]

## 8. 条件触发器
[在什么条件下应该重新评估这个建议]

## 附录
- 完整 source_log
- 完整 evidence_table
- 各轮 subreport 链接
```
