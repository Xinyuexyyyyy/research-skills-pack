# Workspace Layout — 工作区目录约定（单一事实源）

> `/workspace-init` 按它搭，`/workspace-tidy` 按它整。改约定只改这里，两个命令都读这份。

## 一级目录约定（基于三层工作范式）

| 目录 | 放什么 | 对应层 |
|------|--------|--------|
| `research/`  | 调研产物、资料梳理、competitor/paper 笔记 | 调研层 |
| `projects/`  | 正在做的项目（每个项目一个子目录）        | 任务层 |
| `output/`    | 成稿、导出件（PDF/PPT/MD 等可交付）        | 输出层 |
| `docs/`      | 长期文档、规范、个人笔记                   | —      |
| `resources/` | 素材、模板、参考资料                       | —      |
| `data/`      | 数据集、原始数据                           | —      |
| `archive/`   | 归档：完成或搁置的东西往这扔               | —      |

## 归类规则（tidy 用，按优先级从上到下）

1. **明显垃圾**：`.DS_Store`、`Thumbs.db`、`*.tmp`、空目录 → 标记待删（不自动删）
2. **临时目录**：名字带 `tmp`/`_tmp`/`temp`/`draft` 且 30 天未动 → 建议移到 `archive/`
3. **裸文件归类**（根目录下的单文件，按扩展名/用途）：
   - `*.py` `*.js` `*.sh` 等脚本 → `scripts/`（不在约定 7 项内，存在则用，否则归 `projects/`）
   - 文档 `*.md` `*.pdf` `*.docx` → `docs/`
   - 数据 `*.csv` `*.json`(数据性) `*.xlsx` → `data/`
   - 图片/素材 → `resources/`
4. **长期未动的项目目录**（90 天未改）→ 建议移到 `archive/`
5. **拿不准的** → 一律标"待定"，列出来问用户，绝不擅自移

## 红线

- tidy **绝不自动删除**文件；要删的只标记，由用户手动删
- tidy **移动前必须出方案、等用户确认**
- init **只新建**，已存在的目录/文件一律跳过，绝不覆盖
- 归档 = 移到 `archive/`，不是删除
