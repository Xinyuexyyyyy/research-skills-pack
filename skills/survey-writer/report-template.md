# Survey Writer — 报告模板

## literature_review 模板

```markdown
# 文献综述：[主题]

## 1. 引言

[研究背景：这个领域为什么重要]
[范围界定：本文综述覆盖什么、不覆盖什么]
[组织方式：本文按什么结构展开]

## 2. 问题定义

[核心问题是什么]
[为什么这个问题难]
[现有方法面临的共同挑战]

## 3. 方法分类

### 3.1 [方法类别A]
[奠基工作 + 核心思路]
[改进工作1]
[改进工作2]
[小结：这类方法的优势和局限]

### 3.2 [方法类别B]
...

## 4. 方法对比

| 方法 | 核心思路 | 数据/场景 | 关键结果 | 局限 |
|---|---|---|---|---|
| [方法A] | | | | |
| [方法B] | | | | |

[文字对比：在什么场景下A更好，什么场景下B更好]

## 5. 数据集与评估

[常用数据集]
[评估指标]
[不同方法在相同数据集上的表现对比]

## 6. 研究空白

[Gap 1：某类场景未被充分研究]
[Gap 2：某两种方法的组合未被尝试]
[Gap 3：评估指标单一]
...

## 7. 未来方向

[基于 gap 的具体建议]
[可行性评估]

## 8. 总结

[一句话概括领域现状]
[最关键的发现]

---

*本综述基于 evidence_table.csv 中 N 篇论文生成，其中 M 篇为高置信度抽取。*
```

## related_work 模板

```markdown
## Related Work

### [子领域A]
[2-3 段，回顾该子领域的主要方法]
[突出与本文工作的关系]

### [子领域B]
...

### 与本文工作的关系
[1 段，说明本文与上述工作的差异]
```

## research_gaps 模板

```markdown
# 研究空白分析：[主题]

## 1. 现有方法概览
[简要总结 evidence_table 中的主要方法]

## 2. 空白分类

### 2.1 场景空白
[哪些场景几乎没有被研究过]

### 2.2 方法空白
[哪些方法组合没有被尝试过]

### 2.3 评估空白
[哪些评估维度被忽视了]

### 2.4 理论空白
[哪些理论假设缺乏验证]

## 3. 影响分析
[每个 gap 如果补上，能带来什么价值]

## 4. 优先级建议
[最值得先补的 gap，以及理由]
```

# 未来工作建议：[主题]

- [建议1] — 对应 gap：
